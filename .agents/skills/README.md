# Agent Skills

The local skills were installed from `mattpocock/skills` and are kept in this repository so project-specific guidance can evolve with the codebase.

Use `grill-with-docs` and `domain-modeling` when product language or scope changes. Use `research` for unstable external facts. Use `to-spec` and `to-tickets` before multi-step work. Use `tdd` for API contracts, cache behavior, parsers, and bug fixes. Use `codebase-design` when defining a seam, then `code-review` before proposing a commit. Use `diagnosing-bugs` for regressions and `handoff` when work crosses sessions.

`AGENTS.md` is authoritative for authorization and commit behavior. Skills guide process; they do not authorize Git or high-impact changes.
